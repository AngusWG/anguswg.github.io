## 帮助

- `<Alt-s>`: 切换当前站点的 SurfingKeys
- `<Alt-i>`: 进入穿透模式，暂时禁用 SurfingKeys
- `p` : 进入临时穿透模式，暂时禁用 SurfingKeys |
- `;ql` : 显示上一个操作
- `?` : 显示使用说明
- `.` : 重复上一个操作

</div>
<div style="width: 25%;">

## 鼠标点击

- `cf` : 在新标签页中打开多个链接
- `gi` : 跳转到第一个编辑框
- `gf` : 在非活动新标签页中打开链接
- `[[` : 点击当前页面上一个链接
- `]]` : 点击当前页面下一个链接
- `;m` : 鼠标移出上一个元素
- `;fs` : 显示聚焦可滚动元素的提示
- `;di` : 下载图片
- `i` : 跳转到编辑框
- `I` : 使用 Vim 编辑器进入编辑框
- `L` : 进入区域提示模式
- `O` : 打开文本中检测到的链接
- `f` : 打开链接，按 SHIFT 切换重叠提示，按住 SPACE 隐藏提示 |
- `af` : 在活动新标签页中打开链接
- `C` : 在非活动新标签页中打开链接
- `<Ctrl-h>`: 鼠标悬停在元素上
- `<Ctrl-j>`: 鼠标移出元素
- `<Ctrl-i>`: 使用 Vim 编辑器进入编辑框
- `q` : 点击图片或按钮

</div>
<div style="width: 25%;">

## 滚动页面/元素

- `cS` : 重置滚动目标
- `cs` : 更改滚动目标
- `e` : 向上滚动半页
- `U` : 向上滚动整页
- `d` : 向下滚动半页
- `P` : 向下滚动整页
- `gg` : 滚动到页面顶部
- `G` : 滚动到页面底部
- `j` : 向下滚动
- `k` : 向上滚动
- `h` : 向左滚动
- `l` : 向右滚动
- `$` : 一直滚动到右边
- `%` : 滚动到当前页面的指定百分比位置 |
- `;w` : 聚焦顶部窗口
- `w` : 切换框架
- `u` : 向上滚动半页

</div>
<div style="width: 25%;">

## 标签页

- `yt` : 复制当前标签页
- `yT` : 在后台复制当前标签页
- `g0` : 跳转到第一个标签页
- `g$` : 跳转到最后一个标签页
- `gx0` : 关闭左边所有标签页
- `gxt` : 关闭左边标签页
- `gxT` : 关闭右边标签页
- `gx$` : 关闭右边所有标签页
- `gxx` : 关闭除当前标签页外的所有标签页 |
- `gxp` : 关闭正在播放的标签页
- `E` : 向左切换一个标签页
- `R` : 向右切换一个标签页
- `T` : 选择一个标签页
- `;G` : 对当前标签页分组
- `;gt` : 将过滤后的标签页收集到当前窗口 |
- `;gw` : 将所有标签页收集到当前窗口
- `zr` : 重置缩放
- `zi` : 放大
- `zo` : 缩小
- `<Alt-p>`: 固定/取消固定当前标签页
- `<Alt-m>`: 静音/取消静音当前标签页
- `on` : 打开新标签页
- `x` : 关闭当前标签页
- `X` : 恢复关闭的标签页
- `W` : 将当前标签页移动到另一个窗口 |
- `<<` : 将当前标签页向左移动
- `>>` : 将当前标签页向右移动

</div>
<div style="width: 25%;">

## 页面导航

- `gu` : 在 URL 中向上一级路径
- `gT` : 跳转到第一个激活的标签页
- `gt` : 跳转到最后一个激活的标签页
- `gp` : 跳转到正在播放的标签页
- `g?` : 重新加载当前页面，不包含查询字符串（问号后的所有部分） |
- `g#` : 重新加载当前页面，不包含哈希片段
- `gU` : 跳转到当前 URL 层级的根目录
- `;u` : 使用 Vim 编辑器编辑当前 URL，并在新标签页中打开
- `;U` : 使用 Vim 编辑器编辑当前 URL，并重新加载
- `B` : 向后切换一个标签页历史记录
- `F` : 向前切换一个标签页历史记录
- `<Ctrl-6>`: 跳转到最后使用的标签页
- `S` : 后退历史记录
- `D` : 前进历史记录
- `r` : 重新加载页面

</div>
<div style="width: 25%;">

## 会话

- `ZZ` : 保存会话并退出 |
- `ZR` : 恢复上一个会话 |

## 使用搜索引擎搜索选中内容

- `sg` : 使用谷歌搜索选中内容
- `sd` : 使用 DuckDuckGo 搜索选中内容
- `sb` : 使用百度搜索选中内容
- `se` : 使用维基百科搜索选中内容
- `sw` : 使用必应搜索选中内容
- `ss` : 使用 Stack Overflow 搜索选中内容 |
- `sh` : 使用 GitHub 搜索选中内容
- `sy` : 使用 YouTube 搜索选中内容

</div>

## 剪贴板

- `yG` : 捕获当前完整页面
- `yS` : 捕获滚动元素
- `yv` : 复制元素文本
- `ymv` : 复制多个元素文本
- `yma` : 将多个链接 URL 复制到剪贴板
- `ymc` : 复制表格的多列
- `yg` : 捕获当前页面
- `ya` : 将链接 URL 复制到剪贴板
- `yc` : 复制表格的一列
- `yq` : 复制预格式化文本
- `yi` : 复制输入框文本
- `ys` : 复制当前页面源代码
- `yj` : 复制当前设置
- `yy` : 复制当前页面 URL
- `yY` : 复制所有标签页的 URL
- `yh` : 复制当前页面主机
- `yl` : 复制当前页面标题
- `yQ` : 复制 OmniQuery 的所有查询历史记录 |
- `yf` : 以 JSON 格式复制当前页面的表单数据 |
- `yp` : 复制当前页面用于 POST 的表单数据 |
- `yd` : 复制当前下载 URL
- `cq` : 使用提示查询单词
- `cc` : 打开选中链接或剪贴板中的链接
- `;pp` : 在当前页面粘贴 HTML
- `;pj` : 从剪贴板恢复设置数据
- `;pf` : 使用 yf 中的数据填充表单
- `;cq` : 清除所有待打开的 URL 队列

## 全能栏

- `go` : 在当前标签页中打开 URL
- `Q` : 打开全能栏进行单词翻译
- `ab` : 将当前页面添加到选定文件夹的书签中
- `oi` : 打开无痕窗口
- `om` : 从 Vim 风格标记中打开 URL
- `og` : 打开全能栏进行谷歌搜索
- `od` : 打开全能栏进行 DuckDuckGo 搜索
- `ob` : 打开全能栏进行百度搜索
- `oe` : 打开全能栏进行维基百科搜索
- `ow` : 打开全能栏进行必应搜索
- `os` : 打开全能栏进行 Stack Overflow 搜索
- `oy` : 打开全能栏进行 YouTube 搜索
- `ox` : 打开最近关闭的 URL
- `oh` : 从历史记录中打开 URL
- `H` : 在当前标签页中打开已打开的 URL
- `:` : 打开命令
- `A` : 打开大语言模型聊天窗口
- `t` : 打开 URL
- `b` : 打开书签
- `A` : 打开大语言模型聊天窗口
- `<Ctrl-d>` : 从书签或历史记录中删除聚焦项
- `<Ctrl-i>` : 使用 Vim 编辑器编辑选定的 URL，然后打开 |
- `<Ctrl-j>` : 切换全能栏的位置
- `<Ctrl-.>` : 显示下一页结果
- `<Ctrl-,>` : 显示上一页结果
- `<Ctrl-c>` : 复制选定项的 URL 或所有列出项的 URL
- `<Ctrl-D>` : 从书签或历史记录中删除所有列出项
- `<Ctrl-r>` : 按访问次数或上次访问时间重新排序历史记录 |
- `<Esc>` : 关闭全能栏
- `<Ctrl-m>` : 为选定项创建 Vim 风格标记
- `<Tab>` : 向前循环浏览候选项目
- `<Shift-Tab>`: 向后循环浏览候选项目
- `<Ctrl-n>` : 向前循环浏览输入历史记录
- `<Ctrl-p>` : 向后循环浏览输入历史记录
- `<Ctrl-'>` : 在输入元素中切换引号
- `<ArrowDown>`: 向前循环浏览输入历史记录
- `<ArrowUp>` : 向后循环浏览输入历史记录

- `zv` : 进入可视化模式，并选择整个元素
- `V` : 恢复可视化模式
- `*` : 在当前页面查找选中的文本
- `v` : 切换可视化模式
- `n` : 查找下一个文本
- `N` : 查找上一个文本
- `0` : 向后移动到行首
- `l` : 向前移动一个字符
- `h` : 向后移动一个字符
- `j` : 向前移动一行
- `k` : 向后移动一行
- `w` : 向前移动一个单词
- `e` : 向前移动一个单词
- `b` : 向后移动一个单词
- `)` : 向前移动一个句子
- `(` : 向后移动一个句子
- `}` : 向前移动到段落末尾
- `{` : 向后移动到段落开头
- `$` : 向前移动到行尾
- `G` : 向前移动到文档末尾
- `gg` : 向后移动到文档开头
- `gr` : 朗读选中的文本
- `o` : 跳转到突出显示文本的另一端
- `*` : 搜索光标下的单词
- `<Enter>` : 点击光标下的节点
- `<Shift-Enter>`: 点击光标下的节点
- `zt` : 将光标置于窗口顶部
- `zz` : 将光标置于窗口中心
- `zb` : 将光标置于窗口底部
- `f` : 向前移动到下一个字符
- `F` : 向后移动到下一个字符
- `;` : 重复最新的 f、F 操作
- `,` : 以相反方向重复最新的 f、F 操作
- `p` : 将选择范围扩展到父元素
- `V` : 选择一个单词（w）、一行（l）、一个句子（s）或一个段落（p） |
- `<Ctrl-u>` : 向后移动 20 行
- `<Ctrl-d>` : 向前移动 20 行
- `t` : 使用谷歌翻译选中的文本
- `q` : 翻译光标下的单词

## 代理

- `cp` : 切换当前站点的代理
- `;pa` : 设置代理模式为“始终”
- `;pb` : 设置代理模式为“按主机” |
- `;pd` : 设置代理模式为“直接连接” |
- `;ps` : 设置代理模式为“系统代理” |

## 插入模式

- `<Ctrl-e>` : 将光标移动到行尾
- `<Ctrl-f>` : 将光标移动到行首
- `<Ctrl-u>` : 删除光标前所有已输入的字符 |
- `<Alt-b>` : 将光标向后移动 1 个单词
- `<Alt-f>` : 将光标向前移动 1 个单词
- `<Alt-w>` : 向后删除一个单词
- `<Alt-d>` : 向前删除一个单词
- `<Esc>` : 退出插入模式
- `<Ctrl-'>` : 在输入元素中切换引号
- `<Ctrl-i>` : 为当前输入打开 Vim 编辑器
- `<Ctrl-Alt-i>`: 为当前输入打开 NeoVim 编辑器 |
